# מערכת קליפ מילים לקריוקי (עברית)

כלים ליצירת קליפ וידאו עם מילות שיר שרצות על המסך בסנכרון לקצב הנכון, מעל
שיר אינסטרומנטלי (ללא קול). המערכת בנויה משני חלקים:

1. **`sync_editor.html`** — כלי דפדפן להקלדת תזמון: מנגן את השיר, ואתם
   מקישים (Space) בקצב בכל תחילת שורת מילים. יוצא קובץ תזמון (JSON/LRC).
2. **`render_karaoke.py`** — סקריפט פייתון שלוקח את קובץ התזמון + קובץ
   השמע ומייצר קליפ MP4 עם המילים מודגשות מילה-אחרי-מילה, בעברית מימין
   לשמאל, כולל תצוגה מקדימה של השורה הבאה.

## שלב 1: תזמון המילים לקצב

1. פתחו את `sync_editor.html` בדפדפן (לחיצה כפולה על הקובץ, אין צורך
   בשרת).
2. טענו את קובץ השמע (האינסטרומנטל שלכם).
3. הדביקו את מילות השיר בתיבת הטקסט — **שורה אחת = יחידת קריוקי אחת**
   (בד"כ שורת שיר או חצי שורה). לחצו "טען שורות".
4. לחצו "התחל סנכרון". השיר יתחיל לנגן ותוצג השורה הראשונה.
5. לחצו **רווח** (או על הכפתור הגדול) בדיוק ברגע שהשורה המוצגת אמורה
   להתחיל להישמע. הכלי יעבור אוטומטית לשורה הבאה.
   - טעיתם? **Backspace** מבטל את ההקשה האחרונה וחוזר שורה.
   - קשה לתפוס את הקצב? הורידו את מהירות הנגינה ל-0.75x או 0.5x — הכלי
     מודד את הזמן האמיתי בשיר, לא את המהירות המוצגת.
   - יש לכם זמן תגובה קבוע (מקישים תמיד קצת מאוחר)? כווננו את "היסט
     גלובלי" (למשל ‎-0.15‎ שניות) כדי לפצות על כך אוטומטית בכל ההקשות.
6. בסיום — לחצו "⬇ ייצוא JSON לתזמון" ושמרו את `karaoke_timing.json`.

## שלב 2: יצירת הקליפ

דרוש `ffmpeg` מותקן (עם תמיכה ב-libass) ו-Python 3.

```bash
python3 render_karaoke.py \
  --audio song.mp3 \
  --timing karaoke_timing.json \
  --out karaoke.mp4
```

אפשרויות נוספות:

```bash
python3 render_karaoke.py \
  --audio song.mp3 \
  --timing karaoke_timing.json \
  --out karaoke.mp4 \
  --bg cover_art.jpg \          # תמונת רקע (ברירת מחדל: רקע כהה אחיד)
  --width 1920 --height 1080 \  # רזולוציה (ברירת מחדל 1280x720)
  --font "Arial" \              # פונט (חייב לתמוך בעברית)
  --fontsize 70 \
  --primary-color "&H0000D7FF" \  # צבע המילים ש"כבר נשרו" (זהב, ברירת מחדל)
  --secondary-color "&H00FFFFFF" \ # צבע מילים שטרם הגיע תורן (לבן)
  --offset 0.1                  # הזזת כל התזמון בשניות (תיקון עדין)
```

הקובץ שנוצר (`karaoke.mp4`) מכיל את קטע האודיו שסיפקתם + כתוביות
הקריוקי "צרובות" לתוך הווידאו, עם השורה הנוכחית מודגשת מילה-אחרי-מילה
ותצוגה מקדימה עמומה של השורה הבאה מתחתיה.

## פורמט קובץ התזמון

ניתן גם לכתוב/לערוך את קובץ התזמון ידנית (JSON):

```json
{
  "audio_file": "song.mp3",
  "duration": 180.0,
  "lines": [
    {"start": 0.5, "end": 2.8, "text": "שלום עולם יפה"},
    {"start": 2.8, "end": 5.2, "text": "זהו שיר קריוקי לדוגמה"}
  ]
}
```

דוגמה מלאה נמצאת ב-`example/example_timing.json`. נתמך גם פורמט
`.lrc` הסטנדרטי (`[mm:ss.xx]טקסט השורה`) כקלט ל-`--timing`.

חלוקת המילים בתוך כל שורה להדגשה מילה-אחר-מילה מתבצעת אוטומטית לפי
משך השורה ואורך כל מילה — אין צורך לתזמן כל מילה בנפרד.

## הדרך המדויקת ביותר: תמלול אוטומטי (`transcribe_align.py`)

אם יש לכם **פס קול מבודד** של הזמר, זו הדרך הטובה ביותר — היא נותנת
תזמון ברמת המילה הבודדת בלי הקשה ידנית ובלי הערכות מעוצמת האות.

```bash
pip install faster-whisper
python3 transcribe_align.py \
  --vocal lead_vocal.mp3 \
  --lyrics song.txt \
  --out karaoke_timing.json \
  --model large-v3 \
  --transcript transcript.json    # שומר את התמלול, כדי לא להריץ שוב
```

Whisper מחזיר חותמות זמן לכל מילה, אבל התמלול שלו בעברית יכיל טעויות.
לכן הכלי **מצמיד** את המילים שזוהו למילים האמיתיות ששלחתם (יישור רצפים
בשיטת Needleman-Wunsch לפי דמיון מילים), וכל מילה אמיתית מקבלת את
התזמון של המילה שזוהתה מולה. מילה שהמנוע פספס מקבלת זמן באינטרפולציה
מהשכנות. **הטקסט שמוצג על המסך הוא תמיד שלכם — רק התזמון מגיע מהמנוע.**

במבחן עם תמלול שהושחת בכוונה (10% מילים חסרות, 25% מעוותות, ומילים
מומצאות): 89% הוצמדו נכון, שגיאת תזמון חציונית 0.05 שניות.

הערה: הורדת מודל התמלול חסומה בסביבות ריצה מנוהלות מסוימות. הריצו את
הכלי הזה על מחשב רגיל.

## דרישות

- Python 3.8+ (ללא תלויות חיצוניות — משתמש רק ב-stdlib)
- `ffmpeg` בגרסה עם `libass` (רוב חבילות ffmpeg הרשמיות כוללות זאת)
- דפדפן מודרני כלשהו להרצת `sync_editor.html`
